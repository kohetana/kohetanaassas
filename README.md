# Лабораторная работа №2: Циклы с предусловием и постусловием
## Описание задачи
Программа моделирует процесс охлаждения жидкого свинца.  
Исходная температура свинца: \( t_{ж} = 800^\circ C \).  
Температура затвердевания: \( t_{тв} = 327^\circ C \).  
Охлаждение происходит по экспоненциальному закону до момента затвердевания,  
после чего температура изменяется линейно.
Программа вычисляет среднюю температуру свинца \( t_{cp} \) для моментов времени  
\( \tau = 10, 20, 30, 50, 100 \) минут.
## Формулы
1. Время затвердевани  
2. Средняя температура
## Входные данные
Пользователь вводит с клавиатуры:
- Начальную температуру \( t_{ж} \) (по умолчанию 800)
- Температуру затвердевания \( t_{тв} \) (по умолчанию 327)
- Коэффициент охлаждения (0.021)
- Линейный коэффициент (0.0151)

## Выходные данные
Таблица значений:
- Время \( \tau \) (мин)
- Средняя температура \( t_{cp} \)
